
# Magangkuy - Frontend Login Page

Magangkuy adalah prototype portal magang mahasiswa yang dirancang untuk membantu mahasiswa menemukan peluang magang dan mengelola perjalanan magangnya.

Repository ini merupakan implementasi halaman Login Magangkuy berdasarkan wireframe yang dibuat menggunakan Figma.

## Informasi Proyek

- Nama: Magangkuy
- Jenis: Website Frontend
- Mata Kuliah: Pemrograman Frontend Website
- Institusi: Institut Teknologi Tangerang Selatan (ITTS)
- Teknologi: HTML5, CSS3, JavaScript

## Fitur

1. Halaman login responsif untuk desktop dan Android.
2. Form email dan kata sandi.
3. Validasi input menggunakan HTML5.
4. Fitur tampilkan dan sembunyikan kata sandi.
5. Checkbox Ingat Saya.
6. Tombol login interaktif.
7. Navigasi pendaftaran dan bantuan.
8. Footer informasi website.

## Cara Menjalankan

1. Clone repository:

   git clone https://github.com/PaKu211/frontend-magangkuy.git

2. Masuk ke folder proyek:

   cd frontend-magangkuy

3. Buka file `index.html` menggunakan browser.

Website dapat dijalankan tanpa instalasi dependency tambahan.

Alternatifnya, gunakan ekstensi Live Server pada Visual Studio Code untuk menjalankan website secara lokal.

## Responsive Design

Website menggunakan CSS Media Query agar tampilan dapat menyesuaikan berbagai ukuran layar.

- Desktop: Layout dua kolom.
- Tablet: Layout satu kolom.
- Android: Layout satu kolom dengan ukuran elemen yang disesuaikan.

## Interaktivitas JavaScript

JavaScript digunakan untuk:

- Menampilkan dan menyembunyikan kata sandi.
- Memvalidasi form login.
- Menampilkan pesan simulasi login.

Proses autentikasi belum terhubung dengan backend atau database.
